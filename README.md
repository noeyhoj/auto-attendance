# LMS+ 출석 도우미

우아한테크코스 LMS+ 페이지의 정상 등교·하교 버튼을 정해진 시간에 확인하고 실행하는 Chrome 확장 프로그램입니다. 확장 프로그램 팝업에서 현재 출석 상태를 확인하거나 등교·하교를 수동으로 실행할 수도 있습니다.

> 이 프로젝트는 LMS+ 또는 우아한테크코스의 공식 제품이 아닌 비공식 보조 도구입니다. 사용 전 교육기관의 출석 규정과 서비스 운영 정책에서 자동 처리를 허용하는지 확인하세요.

## 주요 기능

- 월요일부터 금요일까지 한국 시간 기준으로 자동 실행
- 등교: `09:35–10:00`, 완료될 때까지 1분 간격으로 확인
- 하교: `18:00–18:10`, 완료될 때까지 1분 간격으로 확인
- 팝업을 열 때 LMS+에서 현재 등교·하교 상태를 실시간 확인
- 로그인 만료, 캠퍼스 네트워크 오류 및 버튼 비활성 상태 감지
- 중복 등교·하교 방지
- 등교가 완료되지 않은 상태의 하교 방지
- 18시 이전 수동 하교 시 확인창 표시
- 최종 확인 실패 시 Chrome 데스크톱 알림 표시
- 출석 결과와 완료 시각을 저장하거나 외부로 전송하지 않음

## 동작 조건

- Google Chrome 102 이상
- Chrome이 실행 중이어야 함
- 컴퓨터가 켜져 있고 잠자기 상태가 아니어야 함
- 사용하는 Chrome 프로필에 LMS+ 로그인 세션이 있어야 함
- LMS+가 허용하는 캠퍼스 네트워크에 연결되어 있어야 함
- Chrome 및 운영체제에서 알림이 허용되어 있어야 함

이 확장 프로그램은 캠퍼스 네트워크 제한을 우회하거나 자동 로그인을 수행하지 않습니다. LMS+ 화면에 정상적으로 활성화된 버튼이 있을 때만 실제 웹페이지 버튼을 사용합니다.

## 설치 및 적용 방법

### 1. 저장소 내려받기

```bash
git clone https://github.com/noeyhoj/auto-attendance.git
cd auto-attendance
```

Git을 사용하지 않는다면 GitHub의 **Code → Download ZIP**으로 내려받은 뒤 압축을 풉니다.

### 2. Chrome에 설치하기

1. Chrome 주소창에서 `chrome://extensions`를 엽니다.
2. 오른쪽 위의 **개발자 모드**를 켭니다.
3. **압축해제된 확장 프로그램을 로드합니다**를 누릅니다.
4. 이 저장소의 루트 폴더를 선택합니다. `manifest.json`이 바로 보이는 폴더여야 합니다.
5. Chrome 도구 모음에서 **LMS+ 출석 도우미** 아이콘을 고정합니다.
6. 같은 Chrome 프로필로 LMS+에 한 번 로그인합니다.

설치 직후 자동 실행은 기본으로 켜집니다.

### 3. 업데이트 적용하기

저장소를 새 버전으로 갱신합니다.

```bash
git pull
```

이후 `chrome://extensions`에서 **LMS+ 출석 도우미** 카드의 **새로고침** 버튼을 누릅니다. 파일만 교체하고 확장 프로그램을 새로고침하지 않으면 이전 코드가 계속 실행될 수 있습니다.

## 사용 방법

확장 프로그램 아이콘을 누르면 팝업이 열립니다. 팝업은 LMS+ 페이지를 잠시 조회해 다음 상태 중 하나를 표시합니다.

- 등교 전
- 등교 완료·하교 전
- 등교와 하교 완료
- 로그인 필요
- 캠퍼스 네트워크 확인 필요
- LMS 화면 확인 실패

상태 확인 결과는 저장하지 않으며, 팝업을 열 때마다 새로 확인합니다. 완료된 작업의 버튼은 비활성화되고, 등교 전에는 하교 버튼도 사용할 수 없습니다.

### 자동 실행

- **자동 실행 켬**: 평일 예약 시간에 등교·하교를 자동으로 확인하고 실행합니다.
- **자동 실행 끔**: 예약 작업과 재시도를 취소합니다. 수동 실행은 계속 사용할 수 있습니다.

### 수동 실행

- **등교하기**: LMS+의 현재 등교 버튼을 확인하고 실행합니다.
- **하교하기**: 오늘 등교 완료 여부를 먼저 확인한 후 하교 버튼을 실행합니다.

이미 완료된 작업은 다시 실행하지 않습니다. 18시 이전에 하교를 시도하면 조기 하교 방지 확인창에서 사용자가 직접 승인해야 합니다.

## 처리 과정

1. 예약 시각 또는 사용자의 수동 실행 요청을 받습니다.
2. 열려 있는 LMS+ 탭이 있으면 재사용합니다.
3. 탭이 없다면 비활성 탭으로 LMS+를 잠시 엽니다.
4. 로그인, 네트워크, 기존 완료 상태와 버튼 활성 여부를 확인합니다.
5. 조건이 맞으면 실제 등교 또는 하교 버튼을 한 번 누릅니다.
6. 화면에 표시된 완료 상태를 확인합니다.
7. 성공하면 재시도를 중단하고 임시 탭을 닫습니다.
8. 실패하면 지정된 최종 확인 시각까지 1분 간격으로 다시 시도합니다.

로그인이 풀린 경우에는 로그인 화면을 열어 사용자가 직접 로그인할 수 있게 합니다. 아이디, 비밀번호, 인증 코드나 로그인 쿠키는 읽거나 저장하지 않습니다.

## 권한과 개인정보

| 권한 | 사용 목적 |
|---|---|
| `alarms` | 예약 실행과 재시도 |
| `notifications` | 성공 및 확인 필요 알림 |
| `scripting` | LMS+ 페이지 상태 확인 및 정상 버튼 실행 |
| `storage` | 자동 실행 설정과 로그인 화면 탭 식별자 저장 |
| LMS+ 사이트 접근 | 지정된 LMS+ 도메인에서만 화면 상태 확인 |

확장 프로그램은 다음 정보를 저장하거나 외부로 전송하지 않습니다.

- 등교·하교 성공 또는 실패 결과
- 등교·하교 완료 시각
- LMS+ 아이디와 비밀번호
- 인증 코드와 로그인 쿠키 내용
- 다른 웹사이트의 방문 기록이나 페이지 내용

## 파일 구성

| 파일 | 역할 |
|---|---|
| `manifest.json` | 확장 프로그램 정보와 권한 선언 |
| `service-worker.js` | 일정 예약, 재시도, 탭 관리 및 알림 |
| `schedule.js` | 한국 시간 기준 평일 일정 계산 |
| `content.js` | LMS+ 화면 상태 확인과 버튼 실행 |
| `popup.html`, `popup.css`, `popup.js` | 확장 프로그램 팝업 화면 |
| `icons/` | 확장 프로그램 및 알림 아이콘 |
| `tests/` | 일정, 페이지 처리, 팝업 상태 및 저장 정책 테스트 |
| `USER_GUIDE.md` | 상세 사용자 설명서 |

## 테스트

별도 패키지 설치 없이 Node.js 내장 테스트 러너로 검사할 수 있습니다.

```bash
node --test tests/*.test.js
```

## 문제 해결

| 증상 | 확인할 항목 |
|---|---|
| 자동 실행이 되지 않음 | Chrome 실행 여부, 컴퓨터 잠자기 상태, 자동 실행 스위치 |
| 로그인 화면이 열림 | 같은 Chrome 프로필에서 LMS+ 로그인 완료 |
| 캠퍼스 네트워크 오류 | 캠퍼스 Wi-Fi 또는 허용된 유선 네트워크 연결 |
| 현재 상태가 표시되지 않음 | LMS+ 로그인 여부와 페이지 접근 가능 여부 |
| 버튼을 찾지 못함 | LMS+ 화면 구조나 버튼 문구 변경 여부 |
| 알림이 보이지 않음 | Chrome·운영체제 알림 권한과 집중 모드 |
| 변경 사항이 반영되지 않음 | `chrome://extensions`에서 확장 프로그램 새로고침 |

## 알려진 제한사항

- Chrome 예약 기능은 정확한 초 단위 실행을 보장하지 않습니다.
- 컴퓨터가 잠자기 상태이거나 Chrome이 완전히 종료되어 있으면 예약 작업을 실행할 수 없습니다.
- 평일 공휴일을 별도로 인식하지 않습니다.
- LMS+에 CAPTCHA나 추가 사용자 인증이 생기면 자동으로 처리하지 않습니다.
- LMS+의 버튼 문구나 화면 구조가 변경되면 선택 규칙을 수정해야 할 수 있습니다.
- 실제 캠퍼스 네트워크와 로그인된 계정에서 최종 동작을 확인해야 합니다.

자세한 내용은 [사용자 설명서](USER_GUIDE.md)를 참고하세요.
